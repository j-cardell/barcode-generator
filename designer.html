Code 39 — A–Z (case-insensitive), 0–9, space, - . $ / + % · e.g. 07.30.6.2 ✅
Code 128 — any ASCII characters · e.g. 07.30.6.2 ✅
EAN-13 — exactly 12 or 13 digits (check digit added automatically if 12) · e.g. 1234567890128
EAN-8 — exactly 7 or 8 digits (check digit added automatically if 7) · e.g. 1234567
UPC-A — exactly 11 or 12 digits (check digit added automatically if 11) · e.g. 123456789012
ITF-14 — exactly 13 or 14 digits (check digit added automatically if 13) · e.g. 12345678901234
MSI — digits only · e.g. 12345678
Codabar — digits and - $ : / . +, optional start/end letter A–D (added automatically if missing) · e.g. A073062D or 07.30.6.2
Pharmacode — a whole number from 3 to 131071 · e.g. 12345
Format: location | name | text below
The delimiter is |, so colons are fine inside any field. To leave a field blank, just leave it empty between the bars.
Examples:
 • 07.30.6.2 | Seed 7lb | 4ea/case — all three fields
 • 09.26.4.1||6ea/case — no name (blank middle field)
 • 09.20.5.1 | Insecticide 500ml — no text below
 • 08.20.5.2 — location only
